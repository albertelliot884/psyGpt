# 课程文档吸收证据总索引

## 说明
本索引用于汇总当前项目中已完成的“课程文档吸收证据表”，说明哪些学科已经形成可存档证据、证据类型属于哪一类，以及当前整体结论。

这些证据表并不等同于逐页逐段来源证明，因为当前题目数据未显式维护 `sourceDoc` 字段；但它们已经可以作为项目内部的阶段性证据材料，说明课程文档确实被实际吸收到学科结构、题目设计和答案表达之中。

## 当前整体结论

当前至少有以下 6 门学科，已经能够拿出可落文件的课程文档吸收证据：

- 实验心理学
- 教育心理学
- 发展心理学
- 社会心理学
- 普通心理学
- 当代心理与教育统计学

其中：
- **实验心理学**的证据最硬，已经可以落到具体题目 ID 与关键词线索。
- **普通心理学**目前也已经可以落到具体题目 ID，并能明确指出 4 个章节的定点吸收结果。
- **当代心理与教育统计学**虽然更偏结构级与重点/易混点组织级证据，但已经能较稳定说明课程文档参与了统计学复习主干与防错框架的形成。
- **教育心理学、发展心理学、社会心理学**虽然更多采用归纳型证据，但都已能较稳定地说明：课程文档不是“看过就算”，而是已经实际参与了章节结构重建、题目组织与答题表达方式的形成。

因此，可以较有把握地得出当前阶段结论：

> **你提供的课程文档，确实已经被系统吸收到项目中，而且至少在 6 门学科上已形成可存档的证据材料。**
