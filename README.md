# 心理学考研专业课复习网页

一个适合部署到 GitHub Pages 的静态复习网页，当前已完成普通心理学的增强版整理，并支持本地错题本、本地内容管理、题目与重点/易混点关联维护，以及可持续训练的本地试卷系统。实验心理学现已扩展为 10 章成熟样板版，并完成多轮内容加厚、主观题卷面化收口与参考文档并入；社会心理学也已按参考文档扩展为 12 章基础样板版，并完成第三轮加厚与本轮收口；发展心理学也已按参考文档重建为 11 章基础样板版，并完成第三轮加厚与本轮收口；心理与教育测量也已完成基础样板版，并完成第三轮加厚与本轮收口；当代心理与教育统计学也已完成基础样板版，并完成第三轮加厚与本轮收口；教育心理学现已按参考文档重建为 17 章基础样板版，并完成第三轮加厚与本轮收口。

- 支持本地导入 / 导出 JSON
- 支持本地试卷系统：组卷、作答、自动保存、交卷、复盘、历史恢复、错题再练、进度回灌

## GitHub Pages 部署方式

### 1. 上传仓库
把当前项目完整上传到 GitHub 仓库，保持 `webapp/` 与 `data/` 在仓库根目录同级。

### 2. 打开 GitHub Pages
在仓库设置中：

- 进入 **Settings**
- 打开 **Pages**
- Source 选择你的默认分支（如 `main`）
- Folder 选择 `/ (root)`

### 3. 访问地址
部署成功后可通过以下任一方式访问：

- 根地址：
  - `https://你的用户名.github.io/你的仓库名/`
- 首页直达地址：
  - `https://你的用户名.github.io/你的仓库名/webapp/psy-index.html`

根目录 `index.html` 已自动跳转到 `./webapp/psy-index.html`。

## 使用说明

### 普通访问
直接从首页进入即可，推荐路径：

- 首页
- 学科复习
- 单章复习
- 测试卷中心
- 复习进度
- 内容管理

### 内容管理说明
内容管理页支持：

- 题目管理
- 重点管理
- 易混点管理
- 关联重点 / 易混点维护
- 本地导入 / 导出

### 测试卷中心说明
当前试卷系统已不再只是 MVP 展示页，已支持以下本地训练链路：

- 按章节卷 / 高频冲刺卷 / 真题风格卷组卷
- 按题型直接在页面作答
- 本地自动保存当前试卷作答状态
- 刷新或重新进入页面后恢复当前试卷
- 交卷后进入复盘模式
- 客观题直接核对答案
- 主观题按 `scoringPointGroups.core` / `scoringPointGroups.extra` 展示“必写点 / 可补充点”
- 主观题支持基于保守关键词命中法的得分点覆盖提示
- 客观题错题自动沉淀到错题本
- 薄弱章节可由试卷结果自动回推到进度页
- 支持最近试卷恢复、历史原作答恢复、基于历史错题再练
- 支持历史作答与本次重做的前后对照复盘

### 本地存储边界
本项目当前是**纯静态站方案**，因此以下功能依赖浏览器本地存储：

- 错题本
- 本地内容管理结果
- 导入后的本地覆盖数据
- 当前试卷 session
- 试卷历史记录与交卷结果快照
- 历史作答恢复所需的答案快照

这意味着：

- 换浏览器、换设备、清缓存后，本地数据可能不会保留
- GitHub Pages 上的内容管理不会直接改写仓库里的 `data/*.json`
- 如需长期保留本地修改，请及时使用“导出 JSON”备份

## 题量控制规则

### 总原则
- 题量规定默认作为**最低要求**，不是所有章节必须完全等量的死上限
- 执行口径为：**下限刚性，上限弹性**
- 重点章允许适度更厚，但不能依赖重复题、低质量题或失衡堆题来拉高数量

### 处理顺序
当不同章节题量不平衡时，统一按以下顺序处理：

1. 先补薄章
2. 再审厚章是否重复
3. 最后才考虑删题

即：**优先补薄，不优先砍厚**。

### 允许超出的前提
某章题量高于规定数量时，可保留，但需同时满足：

- 题目不重复
- 题型结构更完整，而不是更单一
- 新题补到了新考点、新问法或新增训练价值
- 没有明显破坏章节间平衡
- 页面展示、滚动负担与训练体验仍然稳定

### 需要收缩的情况
出现以下情况时，应考虑合并、替换或删除：

- 同考点重复换壳
- 只是凑数的空泛主观题
- 选择题不能独立作答
- 同章题量明显高于其他章且没有足够理由
- 题型严重失衡，例如几乎全部堆成简答题

### 分学科建议区间
- 普通心理学：主干学科，允许更厚，优先保证内容完整与教材结构稳定
- 实验心理学：建议控制在 **10–12 题/章**；低于 `10` 优先补，高于 `12` 进入复审区
- 社会 / 发展 / 教育心理学：基础样板版阶段先保结构完整，后续按轮次逐步加厚
- 统计 / 测量：先保守做稳，优先保证定义准确、训练可做、结构清楚

### 主观题与客观题补题原则
- 主观题优先补高频简答、教材常见比较题、可直接写卷面的概括题、真题风格常见问法
- 不优先补空泛大题、重复改写题、只讲套路不给正文答案的题
- 客观题新增必须能让用户独立作答，干扰项有效，并能服务于易混点区分

### 统一工作口径
> 题量规定是下限，不是死上限；优先补薄章，谨慎删厚章；保留高质量增量，清理重复和凑数题。
