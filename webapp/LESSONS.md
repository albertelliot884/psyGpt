# 教学板块规划

当前已加入页面：
- learn.html

当前已覆盖主题：
- 音程
- 五度圈
- 调号与调性
- 三和弦入门
- 节奏与拍号
- 音阶与调式（大调 / 自然小调 / 五声音阶入门）
- 和弦功能（主功能 / 下属功能 / 属功能）
- 终止式
- 七和弦
- 转调入门
- 借用和弦与副属和弦入门
- 识谱常见误区
- 推荐学习顺序

当前已具备的交互：
- 交互式五度圈
- 音程判定工具
- 固定小测
- 随机小练习
- 章节测验
- 章节测验逐题反馈
- 阶段性综合测试
- 节奏点击练习
- 听感训练引导
- 分级 Web Audio 音程练耳
- 分级 Web Audio 和弦听感训练
- 分级 Web Audio 终止式听感训练
- 练耳阶段考试
- 节奏先播放再复现
- 学习阶段徽章
- 练耳考试分级徽章
- 课程总进度面板
- 识谱区域模式（全范围 / 中线 / 相近 / 远距 / 常用 / 加线）
- 调号语境训练（无调号 / C / G / D / A / E / F / Bb / Eb / Ab / a / e / d / g / c）
- 调号连续训练视角（固定当前调 / 近关系轮换 / 同主音对比）
- 训练器页调号上下文提示卡（基准调 / 当前题语境 / 模式 / 目标）
- 调号上下文 mini session（固定调 → 近关系 → 同主音对比）
- mini session 阶段 chips 可视化进度
- mini session 完成成绩单与一键再来一轮
- 本地学习进度保存与重置
- 教学页跳转训练器并携带细化 `lesson` / URL 预设参数
- 训练器页显示章节来源、训练目标与配置摘要
- 训练器页按 `lesson` 显示章节专属建议卡（目标 / 建议步骤 / 快速练法）

当前反馈能力：
- 正确答案展示
- 逐题结果反馈
- 错因 / 判断依据提示
- 综合测试复盘
- 节奏拍位错误提示
- 阶段达成反馈
- 分级听感训练反馈
- 和弦/终止式听感反馈
- 练耳阶段考试复盘
- 练耳考试等级徽章反馈
- 课程总进度与下一步建议反馈
- 训练区域摘要与报告记录
- 调号语境摘要、上下文提示卡与固定调号连续识谱
- 调号上下文统计（本轮出现语境 / 各语境题量 / 语境准确率 / 最弱语境）
- mini session 阶段总结与完成成绩单
- 章节专属建议卡反馈（按音程 / 调号 / 音阶 / 转调等给不同练法）

当前训练器联动已支持：
- `lesson`
- `clef`
- `accidentalMode`
- `positionMode`
- `theoryMode`
- `sourceMode`
- `rangeMin`
- `rangeMax`
- `regionMode`
- `keySignature`
- `keyContextMode`
- `namingMode`
- `timeMode`
- `examSize`
- `autoPlay`

当前教学页已接入细粒度跳转的章节：
- intervals
- circle
- keys
- chords
- rhythm
- scales
- functions
- cadence
- seventh
- modulation
- borrowed

下一步可继续扩展：
- mini session 按最弱阶段提供“重练近关系 / 重练同主音”入口
- 区域固定 session / 分段连续识谱
- 更多调号与大小调体系（后续可继续扩到 B / Db / Gb 以及和声/旋律小调）
- mini session 与课程章节/总进度面板做更紧的联动
- 训练器页针对不同章节显示不同练习建议卡
- 更丰富的和弦类型与转位听辨
- 真正的功能听感进阶题
- 多页课程拆分
