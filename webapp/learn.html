01 音程：音与音之间的距离

音程包含两个维度：度数和性质。这次把小工具升级成了支持升降号的版本，已经能判断更多常见情况。

概念速读

音程要同时看两个维度：字母名跨了几度，以及实际半音数是多少。前者决定“二度 / 三度 / 四度”，后者决定“大 / 小 / 纯 / 增 / 减”。只看其中一个，后面和弦、调性、听感判断都会跟着乱。

判断步骤

  1. 先数音名跨度，确定度数。
  2. 再数半音数，确定性质。
  3. 最后再把两部分合并成完整名称。

常见误区

  • 把度数直接当半音数，这是最常见的起步错误。
  • 忽略升降号，导致 C→E 和 C→Eb 都被粗暴看成同一种音程。
  • 看到黑键就慌，其实仍然按“度数 + 半音数”两步走就行。

例子拆解

E 到 F 是二度框架，但只有 1 个半音，所以是小二度；F 到 B 是四度框架，但半音数比纯四度更大，因此更接近增四度。

这一章和后面内容的关系

  • 音程 → 三和弦：三和弦本质上是多个音程叠起来的结构，不会音程，和弦判断会一直靠背。
  • 音程 → 音阶与调式：音阶为什么像大调、小调、五声音阶，本质都和音程排列有关。
  • 音程 → 听感训练：很多练耳其实是在听不同音程带来的张力差别。

可以把音程理解成后面大量内容的“最小单位”。这一章站稳，后面很多地方都会轻松很多。

速记口诀 / 一眼判断法

  • 先看几度，再看半音。
  • 字母名决定框架，升降号决定细节。
  • 不要跳过中间步骤直接猜大、小、纯。

学完这章你应该会什么

  • 能把常见音程拆成“度数 + 性质”来判断。
  • 能解释为什么同样是三度，还会分大三度和小三度。
  • 做和弦和音阶题时，不再把音程当成模糊感觉。

02 五度圈：调性地图

从 C 开始，每次向上纯五度走，会得到：C → G → D → A → E → B → F♯ → C♯。现在你可以点击调名查看更完整的信息。

概念速读

五度圈不是单纯背图，而是一张“调性距离图”。往右通常升号增加，往左通常降号增加。离得近的调，常常更容易互相转调、借用或形成自然的和声连接。

判断步骤

  1. 先找到当前调在圈上的位置。
  2. 再判断目标调在左边还是右边，相差几步。
  3. 最后把位置关系翻译成调号数量和调性远近。

常见误区

  • 只背调号数量，却不知道左右方向代表什么。
  • 把五度圈当成静态表格，没有用它去判断“近关系”。
  • 遇到转调题时，不会利用五度圈先缩小判断范围。

例子拆解

C 右边一步是 G，所以 G 大调比 C 多一个升号；C 左边一步是 F，所以 F 大调比 C 多一个降号。C、G、F 因为彼此相邻，所以在乐曲里互相靠近会更自然。

这一章和后面内容的关系

  • 五度圈 → 调号与调性：它能帮你更快理解为什么某些调号彼此接近。
  • 五度圈 → 转调：近关系转调通常更常见、更自然，很多判断都能先从圈上距离入手。
  • 五度圈 → 借用 / 副属：有些“突然变味”的和弦，其实就是在靠近其他中心或强化某个邻近方向。

如果说音程是最小单位，五度圈就像后面调性内容的总地图。

速记口诀 / 一眼判断法

  • 往右升号多，往左降号多。
  • 先找 C，再判断目标在左还是右。
  • 相邻调先当近关系看，远距离再提高警惕。

学完这章你应该会什么

  • 能看出常见大调在五度圈上的左右位置。
  • 能快速判断升号 / 降号的大致变化方向。
  • 遇到近关系调、常见转调时，脑中会先有一张地图。

03 调号与调性

调号回答的是“这首曲子默认会带哪些升降号”，调性回答的是“这组音最终围绕哪个中心稳定下来”。同样的调号，可能对应一组关系大小调；真正判断调性时，还要看旋律收束点、主和弦和乐句重心。

概念速读

调号告诉你“这首曲子默认用哪些升降号”，调性告诉你“这组音真正围绕哪个中心稳定下来”。同一个调号，可能对应关系大小调；同一个主音，也可能有大小调两种不同色彩。

判断步骤

  1. 先看调号，把可能范围缩小。
  2. 再看旋律收束点、主和弦和乐句落点。
  3. 最后区分是关系大小调，还是同主音大小调。

常见误区

  • 把“调号相同”误以为“主音相同”。
  • 把“主音相同”误以为“调号也一样”。
  • 只看调号，不看真正的音乐收束中心。

例子拆解

C 大调和 a 小调都没有升降号，但中心不同；C 大调和 c 小调都围绕 C，却因为调号和音阶材料不同，听感会明显分开。

这一章和后面内容的关系

  • 调号与调性 → 和弦功能：不先知道当前调，就不知道哪个和弦才是主功能、属功能。
  • 调号与调性 → 终止式：“有没有真正回家”一定是相对于当前调来说的。
  • 调号与调性 → 转调：判断是不是转调，本质就是看中心是否真的变了。

这一章是在告诉你：后面所有和声判断，都不是脱离调性单独成立的。

速记口诀 / 一眼判断法

  • 先看调号，再看落点。
  • 调号是范围，中心才是答案。
  • 不要把“同调号”误判成“同主音”。

学完这章你应该会什么

  • 能区分“调号”和“调性中心”不是同一回事。
  • 能分清关系大小调与同主音大小调。
  • 看到和声或旋律收束时，会主动拿来辅助判断调性。
  • 调号是写在谱号后面的固定升降号集合。
  • 调性中心常通过结束音、主和弦、旋律重心体现。
  • 关系大小调共享同一组调号，但主音不同、听感不同。

04 三和弦入门

三和弦可以理解成“隔一个音叠一个音”的最基础和声材料。你先不用一下子记太多理论名词，先抓住它们的构成和听感差异就够了。

概念速读

三和弦的核心不是死记三个音名，而是看它内部由两层什么三度组成。只要会拆结构，大三和弦、小三和弦、减三和弦、增三和弦就会变得很清楚。

判断步骤

  1. 先把音整理成叠三度结构，而不是按出现顺序乱看。
  2. 判断根音到三音、三音到五音分别是什么三度。
  3. 再根据内部结构判断和弦类型。

常见误区

  • 没有先整理根音位置，遇到转位就直接看乱。
  • 只看最低音和最高音，不看中间关键结构。
  • 把“听感偏暗”就都粗暴归成小三和弦。

例子拆解

A-C-E：A→C 是小三度，C→E 是大三度，所以是小三和弦；C-E-G#：上下都是大三度，所以是增三和弦。

这一章和后面内容的关系

  • 三和弦 → 和弦功能：先知道和弦是什么，才谈得上它在调里扮演什么角色。
  • 三和弦 → 七和弦：七和弦不是另起炉灶，而是在三和弦上继续叠一层。
  • 三和弦 → 终止式：终止式里的和弦连接，首先仍然是和弦类型与根音关系的问题。

很多人觉得和声难，是因为没有把“三和弦识别”练成基本功。

速记口诀 / 一眼判断法

  • 先排成三度，再判断类型。
  • 先看内部结构，不要只看外壳。
  • 遇到转位，先还原根音位置。

学完这章你应该会什么

  • 能把常见三和弦按内部三度结构分清。
  • 遇到转位时，知道先整理根音再判断。
  • 为后面的功能、终止式、七和弦打下结构基础。
  • 大三和弦：大三度 + 小三度，例如 C-E-G，听感常偏稳定明亮。
  • 小三和弦：小三度 + 大三度，例如 A-C-E，听感常偏内敛。
  • 减三和弦：小三度 + 小三度，张力更强。
  • 增三和弦：大三度 + 大三度，色彩更漂浮。

章节测验：三和弦入门

先判断构成，再判断和弦类型，会比死背名字更稳。

05 节奏与拍号

如果说音高决定“唱什么音”，那节奏决定“什么时候唱、唱多久”。很多人识谱慢，并不只是音高问题，而是拍子没有站稳。

概念速读

节奏解决的是“什么时候发生、持续多久”，拍号解决的是“这些时值如何按拍子组织”。很多识谱慢并不是音认不出，而是拍感不稳，导致看到音符时不知道该怎么在时间里安放。

判断步骤

  1. 先看拍号，判断一小节有几拍、以什么音符为一拍。
  2. 再看每个音符和休止符占多少时值。
  3. 最后把强弱关系和时值一起带进拍感里读。

常见误区

  • 只数音符个数，不数拍子。
  • 把 3/4 和 4/4 都按“平均四拍”去感受。
  • 知道时值名称，却不会把它们放进真实拍感里。

例子拆解

4/4 最基础的强弱关系常是强 弱 次强 弱；如果把它读成三拍型，节奏就会塌掉。识谱时先站稳拍子，再看音高，效率会高很多。

学完这章你应该会什么

  • 能先站稳拍号，再去读音符时值。

06 音阶与调式

音阶是按照一定规则排列的一组音。调式则更像是“这些音在什么气质下被组织起来”。

概念速读

音阶是按规则组织起来的音集合，调式则更像“这些音围绕哪个中心、呈现什么气质”。同样是一组音，不同中心、不同层级关系，会让听感完全不同。

判断步骤

  1. 先看使用了哪一组音材料。
  2. 再看哪个音最像中心、落点和稳定点。
  3. 最后判断它更接近大调、小调、五声音阶还是其他调式感觉。

常见误区

  • 把音阶当成机械上下行，不理解中心感。
  • 只记“大调亮、小调暗”，却不会落回到具体音材料。
  • 看见五声音阶就只想到民族风，而忽略它在流行旋律中的普遍性。

例子拆解

五声音阶常让人感觉更顺口，一个重要原因是它减少了部分半音摩擦；而大调、小调除了音程结构不同，更重要的是它们的中心感和稳定音层级不同。

学完这章你应该会什么

  • 能把“音阶材料”和“调式中心感”区分开来。
  • 能理解为什么大调、小调、五声音阶听感不同。
  • 做旋律与调式判断题时，不会只靠模糊印象猜。
  • 大调音阶：听感通常更明亮、稳定。
  • 自然小调：听感常偏内敛、暗一些。
  • 五声音阶：中国音乐、民谣、流行旋律里都很常见。

07 和弦功能

在基础和声里，最常见的三个功能是：主功能、下属功能、属功能。你可以把它们理解为“稳定 — 推动 — 回归”的关系。

概念速读

功能和声最关键的不是记缩写，而是理解“稳定 — 推动 — 回归”的关系。主功能像家，下属功能像离开家，属功能像最强烈地想回家。

判断步骤

  1. 先确定当前调的主和弦。
  2. 再看给出的和弦更像稳定、过渡还是强推进。
  3. 把它放进前后和弦关系里一起判断，不要孤立看单个和弦。

常见误区

  • 把所有有张力的和弦都误判成属功能。
  • 只背级数，不理解和声流向。
  • 忘了功能判断永远依赖“当前调”这个前提。

例子拆解

在 C 大调里，C 和弦最稳定，F 会把音乐往外推，G 则最想回到 C。所以 C / F / G 不是三个平行名字，而是三种不同的方向角色。

这一章和后面内容的关系

  • 和弦功能 → 终止式：终止式其实就是功能关系在句末最典型的表现。
  • 和弦功能 → 七和弦：属七和弦之所以重要，是因为它强化了属功能的推动。
  • 和弦功能 → 转调：一旦新的属—主关系稳定建立，常常就是转调开始真正成立的时候。

功能是把单个和弦连成“会走路的句子”的关键一步。

速记口诀 / 一眼判断法

  • T 像家，S 像离开，D 像最想回家。
  • 先定调，再谈功能。
  • 不要孤立看一个和弦，要看它往哪走。

学完这章你应该会什么

  • 能把主 / 下属 / 属功能和“稳定—推动—回归”连起来。
  • 看和弦连接时，会主动去想它在往哪里走。
  • 后面遇到终止式、属七、转调时不再完全割裂。
  • 主功能（T）：最稳定，像“家”。在 C 大调里常见是 C 和弦。
  • 下属功能（S）：有离开主音中心的趋势。在 C 大调里常见是 F 和弦。
  • 属功能（D）：最有推动和解决需求。在 C 大调里常见是 G 或 G7。

08 终止式：音乐句子如何“收住”

终止式可以理解成音乐里的“句号”或“逗号”。它不只是和弦顺序问题，更会直接影响你听到的是“真的结束了”还是“先停一下”。

概念速读

终止式关心的是“句子最后落在哪里”。如果真正回到主功能，常像句号；如果停在属功能，常像逗号；如果明明快落地却转去别处，就会有被拐开的感觉。

判断步骤

  1. 先看最后两个和弦是什么。
  2. 再判断最后有没有真正回到主和弦。
  3. 最后区分是完全终止、半终止、变格终止还是阻碍终止。

常见误区

  • 只要感觉“结束了”就都叫完全终止。
  • 把停在 V 和 V→I 混成同一种收束。
  • 忽略 IV→I 这种较柔和但很典型的结束方式。

例子拆解

V→I 常像真正落地；停在 V 更像还没说完；IV→I 则常带一点柔和、补充式的收束感。学会这个差别后，终止式题就不只是背名字了。

这一章和后面内容的关系

  • 终止式 → 调性判断：很多时候你是靠终止位置确认“这首到底回到了哪”。
  • 终止式 → 转调：如果后面在新主音上形成稳定终止，就很像真的转过去了。
  • 终止式 → 借用 / 副属：有些色彩和弦会影响你对句末方向的判断，需要放到整体收束里看。

学终止式，实际上是在学“音乐如何说完一句话”。

速记口诀 / 一眼判断法

  • 先看最后两个和弦。
  • 回到 I 更像句号，停在 V 更像逗号。
  • 别只听“像结束”，要看落在哪。

学完这章你应该会什么

  • 能用“句号 / 逗号”的感觉理解不同终止式。
  • 能先看最后和弦关系，再判断结束类型。
  • 在调性与转调判断中开始利用收束感做证据。
  • 完全终止：通常最像真正落地，常见为 V → I。
  • 半终止：停在属功能上，像句子还没说完。
  • 变格终止：常见 IV → I，像比较柔和的收尾。
  • 阻碍终止：本来以为要回 I，却转去别处，制造“没落稳”的感觉。

09 七和弦：比三和弦更丰富一步

在三和弦上继续往上叠一个三度，就得到七和弦。你可以把它理解成“在原本稳定骨架上再加一层色彩和张力”。属七和弦尤其重要，因为它最常承担推动回主功能的任务。

概念速读

七和弦是在三和弦上继续叠一个三度得到的。它比三和弦更密集，也更容易带出色彩和张力。入门时最重要的是先抓住“它比三和弦多了哪一层感觉”。

判断步骤

  1. 先确认底层三和弦属于哪一类。
  2. 再看顶部叠出的七度是大七、小七还是别的变化。
  3. 最后结合当前调，判断它的色彩和解决方向。

常见误区

  • 一看到四个音就慌，忘了它本质还是“在三和弦上继续叠三度”。
  • 把属七和弦当成所有七和弦的唯一代表。
  • 不结合当前调去判断解决方向，只盯着名字看。

例子拆解

G7 在 C 大调里最常回到 C，因为它不只是“四个音叠起来”，而是在当前调中承担最典型的属功能推动。理解“为什么它想回去”，比背名字更重要。

这一章和后面内容的关系

  • 七和弦 → 和弦功能：七度的加入常会强化原本的功能方向，尤其是属功能。
  • 七和弦 → 终止式：属七进入主和弦，是很多句末强收束的重要来源。
  • 七和弦 → 转调 / 副属：很多副属和弦会以七和弦形式出现，让方向感更明显。

学七和弦，不是把三和弦推翻，而是让你看到和声为什么会更“会说话”。

学完这章你应该会什么

  • 能理解七和弦是在三和弦基础上增加的一层色彩与张力。
  • 能区分“只是四个音”与“有明确解决方向”的差别。
  • 为副属和弦、强属功能判断打下基础。
  • 大七和弦：大三和弦 + 大七度，色彩细腻。
  • 属七和弦：大三和弦 + 小七度，解决倾向很强。
  • 小七和弦：小三和弦 + 小七度，流行和爵士里很常见。
  • 半减七和弦：比普通三和弦更不稳定，常用于导向。

10 转调入门：音乐为什么会“换了一个家”

转调不是简单出现一个临时升降号，而是音乐重心真的逐渐搬到了另一个调性中心。很多初学者会把“有变化音”误以为“已经转调”，但真正的转调通常会伴随新的主音重心、新的属功能和更明确的落地感。

概念速读

转调不是“出现一个变化音”这么简单，而是音乐的重心真的开始向新主音搬移。也就是说，新的中心、属功能和收束感会逐步建立起来，而不是只在表面多了一个升降号。

判断步骤

  1. 先看变化音是不是持续出现，还是只是一闪而过。
  2. 再看有没有新的属—主关系在建立。
  3. 最后确认音乐是否真的在新中心落地，而不只是短暂借色。

常见误区

  • 只要看到临时升降号就立刻判成转调。
  • 把借用和弦、副属和弦也全都误判成正式转调。
  • 不看后续收束，只看单个瞬间和弦。

例子拆解

从 C 大调转向 G 大调时，如果后面不断强化 D→G、G 的稳定感，并在 G 上落地，那才更像真正转过去；只出现一个 F#，通常还不够下结论。

这一章和后面内容的关系

  • 转调 → 调号与调性：它是“调性中心变化”这件事最动态的版本。
  • 转调 → 五度圈：很多常见转调都能先用五度圈判断远近和自然程度。
  • 转调 → 借用 / 副属：这几者最容易混淆，关键是看有没有真正搬到新中心。

这一章会把前面学到的调性、功能、终止感全部串起来，是综合度很高的一章。

速记口诀 / 一眼判断法

  • 有变化音，不等于已转调。
  • 要看新属音、新主音、新落地。
  • 先找“有没有真的搬家”，再下结论。

学完这章你应该会什么

  • 不会再把所有变化音都直接判成转调。
  • 会看新中心、新属功能和新落地是否真正建立。
  • 能把转调和借用 / 副属区分得更清楚。
  • 临时变化音可能只是装饰、经过或短暂色彩，不一定构成转调。
  • 真正转调通常会出现新调的属和弦、主和弦或更稳定的收束。
  • 近关系转调最常见，因为听感更自然，例如 C 大调转到 G 大调、F 大调或 A 小调。

重点先分清“临时变化”和“真正重心改变”。

11 借用和弦 / 副属和弦入门

当你听到某个和弦突然让颜色更浓、方向更强，往往已经开始碰到借用和弦或副属和弦了。入门阶段不用一次把所有标记背完，先抓住“它为什么突然更有味道”。

概念速读

借用和弦、副属和弦都属于“暂时偏离原调”的常见手法。它们的关键不是把你完全带到新调，而是给原本的和声骨架增加颜色或方向感。

判断步骤

  1. 先确认原调基准还在不在。
  2. 再看这个和弦是从同主音大小调借来的，还是在临时加强某个目标和弦。
  3. 最后判断它是“加色彩”还是“真的搬家”。

常见误区

  • 看到陌生和弦就直接判成转调。
  • 只记符号，不理解它为什么会让颜色突然变浓。
  • 没有原调基准，导致借用和副属都失去参照物。

例子拆解

C 大调里出现 Fm，常被理解为从同主音小调借来的 iv；D7→G 则更像是临时强化 G 的副属方向。它们都会“变味”，但并不一定意味着已经正式转调。

这一章和前面内容的关系

  • 借用 / 副属 → 调性：它们都建立在“原调还存在”这个前提上。
  • 借用 / 副属 → 功能：很多副属和弦本质是在临时加强某个目标和弦的功能方向。
  • 借用 / 副属 → 转调：它们最容易和转调混淆，所以一定要看有没有真正的新中心建立。

学到这里，你已经开始从“单章知识”走向“综合判断”了。

速记口诀 / 一眼判断法

  • 颜色变了，不一定搬家了。
  • 副属常是“临时推一下”，借用常是“临时染个色”。
  • 先守住原调，再判断是不是偏离。

学完这章你应该会什么

  • 能理解借用和弦 / 副属和弦是在原调框架里加色彩或加推动。
  • 遇到“突然变味”的和弦时，不会立刻误判成正式转调。
  • 开始具备更接近真实音乐分析的综合判断视角。
  • 借用和弦：从同主音大小调借来的和弦，例如 C 大调里借 iv（Fm）。
  • 副属和弦：暂时把某个非主和弦当目标，对它先做一个“属功能推动”。
  • 学习重点：先听出“色彩变化”和“临时导向”，再去熟悉名称。

先听一个两和弦进行，再判断更像真终止、半终止还是阻碍终止。

练耳阶段考试

按当前练耳等级随机抽 3 题，混合音程 / 和弦 / 终止式，做一次小验收。

节奏点击练习

看提示点击 4 格节奏型。● 表示强拍 / 需要点击，○ 表示留空。答对后会记入本地进度。

识谱常见误区

1. 线和间混着背：更稳的做法是分开记，高音谱号先记线再记间，低音谱号也一样。
2. 中央 C 反应慢：把中央 C 当桥梁定位点，一认出来，附近音就能顺着数出来。
3. 只背音名不看走向：识谱不只是认单点，还要看旋律是在上行、下行还是跳进。
4. 忘记调号默认升降：例如 G 大调里的 F 默认就是 F♯，不要每次从零判断。
5. 临时记号作用范围记错：通常只在当前小节、同音名且同八度位置内生效。
纠偏建议
先固定一个谱号和较小范围，把位置感练熟，再扩到混合位置。
调号总是犹豫时，先固定当前调练 1-2 轮，再切近关系轮换。
如果总把加线音看错，建议单独切到“加线”区域模式做短轮训练。

推荐学习顺序

识谱基础：高音谱号自然音 → 低音谱号自然音 → 中央 C 专项 → 线 / 间专项 → 八度强化。
升降号过渡：升号 / 降号练熟后，再进入调号与调性感。
乐理主线：音程入门 → 节奏与拍号 → 音阶与调式 → 调号与五度圈 → 三和弦与和弦功能。

这条顺序更稳，不容易出现“会做题但不知道为什么”的情况。
