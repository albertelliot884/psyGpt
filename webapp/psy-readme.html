Workflow

建议使用顺序

1. 先看学科结构

从普通心理学学科页进入，先按“编 → 章”看全书结构，再决定先复习哪一编、哪一章，不建议一开始就随机做题。

2. 进入单章复习

每章先看章节定位、重点、易混点，再看题目训练，建立“内容—考点—题型”对应关系。当前题目已补入建议字数、建议用时与参考答案，更适合作答训练。

3. 去测试卷中心训练

先做章节卷，再做高频冲刺卷，最后再做真题风格卷，逐步拉高综合要求。做题过程中可以把不会的题直接加入错题本。

4. 在进度页回看

把已通读和薄弱章节标记出来，结合错题本做第二轮回看，不要只做题不回顾。

Feature Update

当前已新增的训练与管理能力

按题型作答训练

题目当前已支持建议字数、建议用时和分题型参考答案展示。简答题、辨析题、论述题不再统一使用同一长度的短答案，整体更贴近考研主观题训练需求。

本地错题本

章节页与试卷页均可手动把题目加入错题本，进度页可统一查看错题概览、错题列表并移出错题本，适合做二轮回看。

本地内容管理

新增内容管理页，可对题目、重点、易混点进行本地增删改查，并支持导入 / 导出 JSON。当前版本适合静态站和 GitHub Pages 场景下的本地维护使用。

题目关联维护

内容管理页已支持为题目勾选关联重点和关联易混点，帮助把题目训练与章节考点、辨析点真正串联起来。

前台复习体验优化

章节页和试卷页题目卡片已优化信息层级，支持直接显示关联重点、关联易混点、参考答案、得分点与解析，错题卡片也更适合作为二轮复习入口。

Data

当前数据结构

学科

`subjects.json` 负责学科层信息。

章节

`chapters.json` 负责章节顺序、摘要、标签等基础骨架；普通心理学当前按教材 5 编 14 章映射。

重点 / 易混点 / 题目

分别由 `focus_points.json`、`confusion_points.json`、`questions.json` 承担，彼此通过显式 ID 关联。

本地管理层

当前内容管理页使用浏览器本地存储覆盖默认数据，不直接改写仓库文件，适合静态站环境中的本地维护、导出与导入。

内容关联层

题目当前可显式维护与重点、易混点之间的关联关系，前台题目卡片也会同步显示这些关联信息，便于按“题目—考点—易混辨析”路径复习。

Source

资料接入原则

不直接按 PDF 做导航

网站结构按“学科 → 章节 → 考点 → 题目”组织，而不是按文件名或 PDF 顺序组织。

扫描 PDF 需 OCR 或人工整理

若资料是扫描件，不能假定可直接提取文本，需要 OCR 或人工摘录后再结构化入库。

内容按复习逻辑整理

内容不是逐页搬运，而是按章节定位、核心概念、重点知识、易混辨析、训练题方向和复习提示重新组织。
