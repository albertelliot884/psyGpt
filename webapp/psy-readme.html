Checklist

实验心理学真实交互验收清单

1. 首页进入学科卡

从 `webapp/psy-index.html` 检查“实验心理学”学科卡是否可见、状态是否合理，并能正常进入 `webapp/psy-subject.html?subject=experimental_psychology`。

2. 学科页结构

确认学科页可正常显示学科说明、当前状态、4 个章节卡片以及“进入本章”入口，且无普通心理学专属文案串台。

3. 章节页展示

至少抽查 `ep_variables` 与 `ep_reaction_time` 两章，确认题目、建议字数、建议用时、参考答案、解析与得分点均能正常显示。

4. 试卷页组卷

在 `webapp/psy-papers.html` 中选择实验心理学，先测试章节卷，再测试基础混合卷或高频卷，确认能够正常生成且不出现空卷。

5. 作答与自动保存

对实验心理学试卷进行主客观题作答，刷新页面后确认当前卷与已作答内容都能恢复。

6. 交卷与复盘

交卷后确认客观题能显示“你的答案 / 正确答案 / 结果”，主观题能显示“你的作答 / 必写点 / 可补充点 / 参考答案 / 解析”。

7. 历史恢复与进度回灌

交卷后检查历史卷卡是否出现、是否可恢复；再进入 `webapp/psy-progress.html`，确认“最近一次试卷结果”能正确接住实验心理学结果。

8. 当前验收重点

重点观察是否出现普通心理学文案串台、卷面过薄、主观题复盘空块或历史/进度未按学科承接等问题。实验心理学当前更适合作为成熟样板版第二轮加厚后的收口学科验收，不以高仿真真题卷为主目标。

Workflow

建议使用顺序

1. 先看学科结构

从普通心理学学科页进入，先按“编 → 章”看全书结构，再决定先复习哪一编、哪一章，不建议一开始就随机做题。

2. 进入单章复习

每章先看章节定位、重点、易混点，再看题目训练，建立“内容—考点—题型”对应关系。当前题目已补入建议字数、建议用时与参考答案，更适合作答训练。

3. 去测试卷中心训练

先做章节卷，再做高频冲刺卷，最后再做真题风格卷，逐步拉高综合要求。当前试卷页已支持逐题作答、本地自动保存、交卷后复盘、历史作答恢复与错题再练，不再只是静态展示页。

4. 在进度页回看

把已通读和薄弱章节标记出来，结合错题本做第二轮回看，不要只做题不回顾。

Data

当前数据结构

学科

`subjects.json` 负责学科层信息。

章节

`chapters.json` 负责章节顺序、摘要、标签等基础骨架；普通心理学当前按教材 5 编 14 章映射。

重点 / 易混点 / 题目

分别由 `focus_points.json`、`confusion_points.json`、`questions.json` 承担，彼此通过显式 ID 关联。

本地管理层

当前内容管理页使用浏览器本地存储覆盖默认数据，不直接改写仓库文件，适合静态站环境中的本地维护、导出与导入。

内容关联层

题目当前可显式维护与重点、易混点之间的关联关系，前台题目卡片也会同步显示这些关联信息，便于按“题目—考点—易混辨析”路径复习。

Source

资料接入原则

不直接按 PDF 做导航

网站结构按“学科 → 章节 → 考点 → 题目”组织，而不是按文件名或 PDF 顺序组织。

扫描 PDF 需 OCR 或人工整理

若资料是扫描件，不能假定可直接提取文本，需要 OCR 或人工摘录后再结构化入库。

内容按复习逻辑整理

内容不是逐页搬运，而是按章节定位、核心概念、重点知识、易混辨析、训练题方向和复习提示重新组织。
