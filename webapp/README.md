# 五线谱识谱学习站

一个纯前端静态学习小站，把 **识谱训练器**、**乐理教学**、**章节小测 / 随机练习** 和 **学习进度** 整合在一起。

## 页面结构
- `home.html`：站点总入口 / 导航页
- `index.html`：五线谱识谱训练器 Pro
- `learn.html`：乐理教学页
- `README.html`：可视化使用说明
- `README.md`：项目说明

## 当前功能

### 训练器
- 训练模式 / 考试模式
- 高音 / 低音 / 混合谱号
- 自然音 / 升号 / 降号 / 混合
- 只练线 / 只练间
- 中央 C 专项 / 加线强化 / 八度强化
- 钢琴键盘输入 / 快捷键输入
- 音频播放
- 错题本 / 重练错题
- 练习报告导出

### 教学页
- 音程
- 五度圈
- 调号与调性
- 三和弦入门
- 和弦功能
- 终止式
- 七和弦
- 节奏与拍号
- 音阶与调式
- 交互式五度圈
- 音程判定工具
- 固定小测 / 随机小练习
- 本地学习进度保存与重置

### 学练联动
- 教学页的“开始本章练习”会跳到训练器
- 使用 `lesson` 参数自动套章节推荐配置
- 训练器支持恢复默认配置

## 使用方式
- 想按站点路线使用：直接打开 `home.html`
- 想直接练习：打开 `index.html`
- 想先学乐理：打开 `learn.html`

## 部署方式
上传整个 `webapp/` 目录到任意静态托管平台即可。

如果想把它作为完整学习站对外展示，建议把 `home.html` 作为导航入口。
