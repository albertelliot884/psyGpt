五线谱识谱学习站 - 使用说明

这是一个纯前端静态学习小站，把识谱训练器、乐理教学、章节小测和学习进度整合在一起。可以直接本地打开，也可以部署到任意静态托管平台。

返回学习站首页 开始识谱训练 开始乐理学习

当前站点包含

训练器

  • 训练模式 / 考试模式
  • 高音、低音、混合谱号
  • 自然音、升号、降号、混合
  • 线 / 间专项、中央 C、加线强化、八度强化
  • 钢琴键盘输入、快捷键输入、题目发声
  • 错题本、重练错题、练习报告导出

教学页

  • 音程、五度圈、调号与调性
  • 三和弦、和弦功能、终止式、七和弦
  • 节奏与拍号、音阶与调式
  • 交互式五度圈、音程判定工具
  • 固定小测、随机小练习、本地学习进度

课程联动

  • 教学页可跳回训练器并携带 lesson 参数
  • 训练器会自动载入对应章节推荐配置
  • 支持恢复默认配置继续自由练习
  • 章节状态可标记、统计、重置

推荐使用方式

  • 初学者：先从 home.html 进入课程地图，再去 learn.html 按顺序学习。
  • 正在练琴的人：直接进 index.html 做识谱训练，遇到概念不稳再去教学页查缺补漏。
  • 考前复习：优先用考试模式和练习报告，再按错题返回对应章节复习。

本地使用

  • 直接双击打开 home.html、index.html 或 learn.html 即可。
  • 推荐使用现代浏览器（Chrome / Edge / Safari）。
  • 首次播放声音时，浏览器可能要求先点击页面一次来解锁音频。

部署方式

  • 把整个 webapp/ 文件夹上传到任意静态托管服务。
  • 例如：GitHub Pages、Vercel、Netlify、静态 Nginx 目录。
  • 如果希望对外作为学习站展示，建议把 home.html 作为导航入口一起提供。

训练器快捷键

  • A~G：作答
  • N：下一题
  • R：重置
  • P：播放当前音
